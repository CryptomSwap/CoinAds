How to Use CoinAds

This page demonstrates how to integrate CoinAds into your website. The ads below are loaded using our JavaScript tag.

Method 1: Auto-initialization with data attributes

<div data-coinads-placement="test-placement-1" data-coinads-width="728" data-coinads-height="90"></div>
728x90 Banner (Auto-initialized)

Method 2: Manual initialization

<div id="coinads-manual-1"></div> <script> CoinAds.init('manual-placement-1', 300, 250); </script>
300x250 Rectangle (Manual)

Method 3: Multiple placements

320x50 Mobile Banner
970x250 Large Banner

Integration Instructions

  1. Include the CoinAds tag script: <script src="https://coinads.com/tag.js"></script>
  2. Add ad containers to your HTML with data attributes or manual initialization
  3. Ads will automatically load when the page loads
  4. Use CoinAds.refresh(placementId) to refresh ads dynamically

Available Methods

  • CoinAds.init(placementId, width, height) - Initialize an ad placement
  • CoinAds.refresh(placementId) - Refresh an existing placement
  • CoinAds.getVersion() - Get the current tag version

Supported Sizes

  • 320x50 (Mobile Banner)
  • 728x90 (Leaderboard)
  • 300x250 (Medium Rectangle)
  • 1920x82 (Large Banner)
  • 970x250 (Large Rectangle)
